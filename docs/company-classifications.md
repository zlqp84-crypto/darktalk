# 공식 분류 검증 · 2026-09-19 수집

## 상장기업

한국거래소 KIND 공식 상장법인목록(검색유형 13, 전체 시장)을 수집했다.
출처: https://kind.krx.co.kr/corpgeneral/corpList.do?method=loadInitPage
원본 2,798행에서 동일 종목코드·회사명·시장 중복 43행을 제거하면 2,755개 법인이다.
다른 명칭/시장으로 종목코드가 중복되면 수집을 실패 처리한다.
모든 2,755개 종목코드는 DART 원본의 단 하나의 corp_code와 일치했다.
회사명만으로 연결하지 않았다. KRX 목록은 조회 시점의 스냅샷이며 실시간 상장 유지 보장이 아니다.

DART 기업개황 1,006건을 먼저 조회했으나 ECONNRESET 통신 오류로 중단했다.
해당 건의 법인구분과 KRX 상장 여부 사이 충돌은 0건이었다. 이후 반복 호출 대신 KRX 전체 목록으로 검증했다.
기업개황의 대표자명·전화번호·주소 등은 결과 파일에 저장하지 않는다.

기존 3,990개 'listed'는 종목코드 존재만으로 만들어져 실제 상장 근거가 부족했다.
20260919020000_listing_provenance.sql은 이를 stock_code_registered로 바꿔 원천 사실을 보존한다.
KRX에서 확인된 2,755개에만 별도 listed 태그를 등록한다. 기존 1,235개는 상장 태그가 제외된다.
새 DART 기본목록 수집기는 상장 태그를 만들거나 덮어쓰지 않는다.

## 공기업·공공기관

출처: https://alio.go.kr/organ/organDisclosureList.do
공식 기관 목록 API의 전체 355개 항목을 페이지별 수집했다. 상위기관 ID가 있는 부설기관 13개를 제외했다.
본기관 342개: 공기업 30개, 기타 공공기관 분류(준정부기관 포함) 312개.
기관별 ALIO 고유번호, 명칭, 홈페이지, 유형, 근거 상세 링크를 사용했다.
기준일 2026-09-19는 원천 조회일이며 ALIO의 법적 변경일로 주장하지 않는다.

ALIO 고유번호는 DART 법인 고유번호와 다른 체계다. 현재는 ALIO 원천 레코드로 별도 등록한다.
이름이 비슷한 DART 법인과 자동 병합하지 않아 같은 법인이 출처별로 중복 검색될 수 있다.
공식 식별자 교차표가 확보되면 리뷰 연결과 기존 URL을 보존하면서 통합한다.
행정기관/공무원 분류를 공공기관과 혼합하지 않는다.
