# 병원 공개 범위

2026-09-28 사용자 선택에 따라 HIRA 출처는 상급종합(01)·종합병원(11)만 공개한다. 병상 수 또는 직원 수 기준이 아니다.

- 기존 HIRA 79,894행을 보존하고 공개 79,886곳 중 범위 밖 79,503곳을 비공개로 전환했다. 공개 대상은 383곳이다.
- 부천우리병원·부천세종병원은 모두 종합병원으로 계속 공개한다.
- 회사 ID, slug, 분류, 리뷰 행은 삭제하거나 변경하지 않는다. 비공개 기관의 공개 상세 페이지는 기존 RLS에 따라 접근할 수 없으며, 통합 별칭도 대상 기관이 비공개면 연결되지 않는다.
- 기존 비공개 기관은 재공개하지 않는다. 종별이 승격된 기존 비공개 기관은 수동 검토 대상이다.
- 원천 전체 스냅샷은 갱신 비교와 중복 추적을 위해 유지한다. 신규 공개는 코드와 명칭이 모두 맞아야 하며 중복 후보는 제외한다. 종별이 범위 밖으로 변경된 기존 공개 기관은 숨긴다.
- 일회성 migration은 `20260928010000_general_hospital_publication.sql`. 기존 테이블·RLS·권한은 변경하지 않는다. 운영에서는 전체/공개/대상 수와 대표 두 병원 검사를 추가한 트랜잭션으로 롤백 검증 후 적용했다.
- 적용 전 운영 리뷰는 0개였다. 리뷰 연결 보존은 격리 DB fixture로 검증했다.

검증: 전체 보안 테스트 274개 통과, production build 통과. 운영 SQL `HOSPITAL_SCOPE_PREFLIGHT_OK` 및 `HOSPITAL_SCOPE_APPLIED` 확인. 공개 API 검증 결과는 `artifacts/companies/hospital-scope-live-result.json`에 보관한다.
