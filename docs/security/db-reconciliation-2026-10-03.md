## 재현 도구

`node scripts/db/prepare-audit.mjs`는 저장소의 migration 및 수동 이미지 전환 순서를 반영해 최종 함수 본문 해시를 계산하고 읽기 전용 SQL과 파일 SHA-256 목록을 `artifacts/db/`에 만든다. 실행은 자동 DB 연결 없이 SQL Editor에서 수행한다. 산출물은 덮어쓰지 않으며 Git 제외 대상이다.

공백 제거 비교는 문자열 리터럴 내부의 공백도 제거하므로 자동 이력 수선의 근거로 사용하지 않는다. 도구는 지원하지 않는 함수 선언을 만나면 중단한다. 함수 이름에 여러 오버로드가 있으면 단일 일치로 판정하지 않는다.

## 남은 필수 단계

1. DB 연결 비밀번호의 안전한 입력 및 백업 도구 준비. service_role API 키는 DB 연결 비밀번호의 대체물이 아니다.
2. 스키마·역할·데이터 및 별도 Storage 파일 백업. 보관 위치·암호화·복구키 관리 선택 필요. `backups/`는 Git 제외했지만, 디렉터리 생성/제외만으로 암호화되지는 않는다.
3. 운영과 분리된 복구 검증 환경 준비 및 복원·권한 테스트.
4. 전체 카탈로그와 migration 재구성 결과를 대조한 후에만 실제 적용 버전을 이력에 등록. 현재 CLI db push/repair를 실행하면 안 된다.
